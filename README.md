# galacticlight.github.io

Portfolio of Galacticlight: an engineer building local-first tools, AI companions, and things made by hand.

Live: https://galacticlight.github.io/

Built with Astro (static output, no client framework). Fonts are self-hosted (Shippori Mincho B1, Inter). No trackers.

```sh
npm install
npm run dev     # local dev server
npm run build   # static build to ./dist
```

Deploys to GitHub Pages through GitHub Actions on every push to `main`.
